# Описание данных

В проекте использованы два датасета о венчурном финансировании стартапов.

## `cb_investments`

Содержит 54 294 записи и 40 признаков:

- название, сайт и статус компании;
- отрасль и категории деятельности;
- страна, регион и город;
- даты основания и финансирования;
- общий объём инвестиций;
- количество раундов и участников;
- суммы по типам финансирования;
- объёмы раундов A–H.

Основные типы финансирования:

- `seed`;
- `venture`;
- `angel`;
- `private_equity`;
- `debt_financing`;
- `equity_crowdfunding`;
- `convertible_note`;
- `grant`;
- `post_ipo_equity`;
- `post_ipo_debt`;
- `secondary_market`;
- `product_crowdfunding`.

## `cb_returns`

Содержит информацию о возвратах средств за 2000–2014 годы:

- `year` — год;
- остальные столбцы — объёмы возвратов по типам финансирования в миллионах долларов.

## Обработка данных

В ходе подготовки данных:

- названия столбцов приведены к `snake_case`;
- финансовые показатели преобразованы в числовой формат;
- даты приведены к типу `datetime`;
- удалены полные дубликаты и записи без финансирования;
- пропуски `mid_funding_at` восстановлены по середине интервала;
- аномальные объёмы финансирования определены методом IQR отдельно по сегментам.

## Доступность

Исходные датасеты не размещены в репозитории. Ноутбук загружает данные из открытого учебного источника.
